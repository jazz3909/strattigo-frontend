05

Usage rules

The disciplines that keep it coherent as it scales to every page.

  • Separation is whitespace, tint, and hairline — never a thick border. If a region needs emphasis, change its background, don't outline it.
  • One accent, three jobs: actions, active states, and moments of warmth. If Dusk Blue is doing a fourth job, question it.
  • Semantic colors are for correctness and system state only — a wrong quiz answer, a failed upload — never for brand.
  • Reading surfaces use document density and the serif body. Working surfaces use app density and the sans. Don't mix.
  • Content owns the page. Chrome (rail, top bar) stays quiet so the guide, the quiz, the materials are the loudest thing on screen.
